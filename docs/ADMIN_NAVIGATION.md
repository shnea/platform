# 관리자 화면 탐색

기능을 찾기 위해 프로젝트 상세를 끝까지 스크롤하지 않도록 주요 메뉴와 프로젝트 내부 탭을 나눈다. 데스크톱은 왼쪽 메뉴, 모바일은 상단 **메뉴 열기**에서 이동한다.

## 주요 메뉴

| 메뉴 | 할 수 있는 일 |
| --- | --- |
| 프로젝트 | 프로젝트 선택·생성, 환경별 인증·회원·키·개발 테스트·설정 |
| 비동기 작업 | 프로젝트·환경을 선택해 작업 상태·시도·이벤트 전달 이력과 재시도 확인 |
| 모니터링 | 플랫폼 서비스 상태·누적 요청/오류율/처리 시간, 선택한 환경의 작업 차트·적체 설정 |
| 운영 알림 | 선택한 프로젝트·환경의 실패·복구 알림, 이메일 수신 설정·발송 이력 |
| 감사 이력 | 최근 관리·인증 활동 조회 |

작업·알림과 모니터링의 **프로젝트 작업** 화면에서 **다른 프로젝트 선택**으로 범위를 바꿀 수 있다. 프로젝트 목록은 20개씩 조회한다. 프로젝트 작업·알림은 선택한 환경 하나를 표시하며 전체 프로젝트 통합 목록은 제공하지 않는다.

모니터링은 **서비스 상태 / 프로젝트 작업**으로 범위를 나눈다. 서비스 상태는 프로젝트를 고르지 않아도 현재 개발/운영 플랫폼의 공통 서비스를 보여 준다. 서비스 재시작 이후 누적 요청·4xx·5xx, 서버 오류율·평균 처리 시간을 비교하며 측정 범위와 시작 시각을 표시한다. 프로젝트 작업으로 돌아가면 같은 프로젝트·환경 선택을 유지한다.

모니터링은 현재 작업 상태와 최근 24시간 완료·실패·취소 차트를 함께 보여 준다. 상태별 작업 보기로 이동하면 해당 상태 필터와 환경을 유지한다. 실패 목록은 전체 기간이며 24시간 차트와 조회 기간이 다르다. [모니터링 지침](MONITORING.md)에 수치의 의미와 갱신 방식을 정리했다.

프로젝트 작업 안에서는 **작업 현황 / 적체 경보 설정** 탭으로 나눈다. 적체 경보의 켜기·시간 기준·연속 확인 횟수를 저장하고 마지막 검사·최근 변경을 조회한다. 발생·해소·감시 종료 이력은 운영 알림에서 구분하며 이메일 주소는 기존 운영 알림의 수신 설정에서 관리한다.

운영 알림은 **알림 목록·수신 설정·발송 이력** 탭으로 나눈다. 설정을 저장하는 동안 주요 메뉴·탭·환경 이동을 막으며, 저장하지 않고 이동한 입력은 유지하지 않는다. 자세한 정책은 [운영 알림 지침](OPERATIONAL_ALERTS.md)을 따른다.

## 프로젝트 내부 탭

| 탭 | 내용 |
| --- | --- |
| 개요 | 환경 반영 상태, 최근 작업 상태, 미확인 알림 존재 여부와 각 화면 이동 |
| 인증 설정 | 로그인 주소 / 가입·복구 정책 / 소셜 로그인으로 구분 |
| 회원 | 회원 조회·로그인 허용 상태·접속 세션 관리 |
| API 키 | 권한·만료일 지정 발급, 상태 조회·폐기 |
| 개발 테스트 | DEV 모의 로그인·테스트 계정 초기화. 개발 모드의 DEV에서만 표시 |
| 프로젝트 설정 | 프로젝트 이름 변경·중지·재개. 모든 환경에 적용 |

**조회 환경**에서 DEV·PROD 등을 선택한다. 환경 만들기는 개요에 있으며, 환경이 없는 프로젝트에서도 제공한다. 인증·회원·키 같은 상세 내용은 해당 탭을 열 때 조회한다. 탭 이동 시 저장 전 입력은 유지하지 않으므로 필요한 설정을 저장한 뒤 이동한다.

## 이동과 조작

- 메뉴를 오가도 같은 프로젝트·환경을 유지한다. 프로젝트 개요의 **작업 보기·알림 보기**에도 선택 범위가 따라간다. 다른 프로젝트 선택 시 이전 환경·키를 비우고 새 범위를 조회한다.
- 같은 프로젝트의 탭 선택도 메뉴를 오가는 동안 유지한다. 새로 로그인하거나 브라우저를 새로고침하면 프로젝트 목록부터 시작한다. 개별 화면 URL·브라우저 뒤로 가기 이력은 아직 제공하지 않는다.
- 탭에서 좌우 방향키·Home·End는 포커스를 옮기고 Enter·Space로 선택한다. Tab으로 본문에 진입할 수 있다. 모바일 메뉴는 Escape로 닫고 호출 버튼으로 포커스를 돌린다.
- 정책·소셜 설정·개발 테스트와 작업 조치가 진행 중이면 메뉴·탭·환경 이동을 막는다. 완료 또는 실패 후 다시 이동할 수 있다. 확인 대화상자의 기존 닫기·포커스·중복 제출 방지 규칙은 유지한다.
- 중지 상태는 문구로 표시하며 영향 설명은 **중지된 프로젝트입니다**를 펼쳐 확인한다.

## 기능을 추가할 때

독립적으로 자주 조회하는 운영 기능은 주요 메뉴에, 특정 프로젝트의 설정은 해당 프로젝트의 탭에 배치한다. 개요에는 요약과 이동만 추가하며 전체 관리 패널을 다시 쌓지 않는다. 미구현 메뉴를 먼저 만들지 않고, 운영 장애 알림과 이용자 메시지 발송 관리는 구분한다.
