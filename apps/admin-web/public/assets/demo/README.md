# 공개 체험 샘플

운영 프로젝트 파일과 무관하게 이 저장소에서 만든 공개 샘플이다.

- `coast.svg`: 직접 작성한 평면 도형 그림. 외부 이미지·폰트·스크립트 없음.
- `sample.txt`: 다운로드 체험을 위해 작성한 안내문.
- `chime.wav`: 523.25Hz 감쇠 사인파, 16kHz mono PCM, 1.5초.
- `video/`: FFmpeg `testsrc2=size=1280x720:rate=24`로 생성한 8초 색상 테스트 영상. H.264, CRF 30, GOP 48, 2초 HLS 세그먼트, 360p·720p. `poster.jpg`도 같은 테스트 패턴이다. 실제 촬영 영상이나 사용자 원본이 아니다.

이 디렉터리의 파일은 게스트에게 공개된다. 실제 회원·프로젝트 자료와 비밀값을 넣지 않는다.
